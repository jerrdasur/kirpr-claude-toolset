- [ ] **Шаг 2: Добавить раздел про kirpr-flow**

Раздел ставится после «Прожарка продуктовых гипотез», перед «Установка».

Содержит:

**Заголовок** третьего уровня: `### Рабочий цикл без git`.

**Абзац о назначении.** Зонтичный скил `kirpr-flow` ведёт работу от идеи до
сдачи: спека, план, исполнение субагентами, ревью, финальная сводка. Ни одной
git-операции: коммиты, ветки и слияния остаются за пользователем.

**Таблица вызовов** — восемь строк, по строке на режим:

| Вызов | Что делает |
|-------|-----------|
| `/kirpr-flow brainstorm <тема>` | Доводит идею до спеки: вопросы, подходы, дизайн по секциям, документ в `docs/kirpr-flow/specs/` |
| `/kirpr-flow plan <спека>` | Превращает спеку в план: каталог с файлом на задачу, у каждой — верификация последним шагом |
| `/kirpr-flow execute <план>` | Исполняет план: свежий субагент на задачу, ревью после каждой, широкое ревью в конце |
| `/kirpr-flow execute --inline <план>` | То же в текущей сессии, без субагентов |
| `/kirpr-flow review <план или файлы>` | Заказывает ревью: субагент читает файлы целиком |
| `/kirpr-flow debug <симптом>` | Разбирает баг: воспроизведение, поиск причины, тест до починки |
| `/kirpr-flow finish` | Сводка работы: сделанное, принятые за вас решения, отложенное, несделанное |
| `/kirpr-flow skill <имя>` | Пишет и правит скилы |

**Абзац про верификацию.** Работа не считается сделанной без доказательства
одного из четырёх форматов: код проверяется тестом, скрипт — запуском, БД —
запросом, документ — чтением целиком. Доказательство — команда и её вывод, а
не пересказ.

**Абзац про отсутствие git.** Набор не коммитит, не ветвится и не сливает —
и не советует, что коммитить. Ревью строится на чтении файлов целиком, а не
на диффе; память между задачами — журнал `progress.md` рядом с планом.
Готовность ветки и судьба изменений остаются на пользователе.

**Абзац про артефакты.** Спеки в `docs/kirpr-flow/specs/`, планы каталогами
в `docs/kirpr-flow/plans/`, там же журнал и отчёты исполнителей. Ничего не
удаляется по завершении: без истории коммитов эти файлы и есть запись о
работе.
