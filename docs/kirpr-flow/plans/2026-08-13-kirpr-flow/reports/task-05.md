### Результат по всем шести пунктам чеклиста задачи

1. **Блок выжимки посимвольно совпадает с `core/rules.md`.** Подтверждено

2. **Подстановки записаны в требуемом виде.** `{ЧТО_ПОСТРОЕНО}`,

   `code-reviewer.md`; `{ПУТЬ_К_СПЕКЕ}`, `{ИСХОДНАЯ_ЗАДАЧА}` — в
   `spec-reviewer.md`; `{ПУТЬ_К_ПЛАНУ}`, `{ПУТЬ_К_СПЕКЕ}` — в
   `plan-reviewer.md`. Все семь подстановок из задачи присутствуют, лишних
   нет.
3. **«Что искать» в `code-reviewer.md` — минимум шесть пунктов.** Ровно
   шесть: несоответствие требованиям, ошибки корректности, дублирование
   логики, лишняя функциональность, неутверждающие тесты, конфликт задач.
4. **По четыре проверки в `spec-reviewer.md` и `plan-reviewer.md`, у каждой
   есть формат вывода.** Подтверждено подсчётом (4 и 4). Оба файла
   заканчиваются разделом «Формат отчёта» с описанием вывода по каждой
