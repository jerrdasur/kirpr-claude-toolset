## Сомнения
- Отступление от источника (осознанное, следует из задачи): в оригинале
  `task-reviewer-prompt.md` и `re-review-prompt.md` ревью строится вокруг
  git-диффа (`[DIFF_FILE]`, `[BASE_SHA]`/`[HEAD_SHA]`, «read the diff file
  once»). В наборе `kirpr-flow` git запрещён полностью, поэтому предметом
  ревью в обоих файлах сделан не дифф, а полный текст файлов из
  {СПИСОК_ФАЙЛОВ} / {ФАЙЛЫ_ЭТОГО_РАУНДА} — задача прямо требует именно
  такую замену («держится на списке файлов и чтении их целиком»), но
  формулировки конкретных фраз («диффа в этом наборе нет, полный текст
  файла и есть предмет ревью») — моя переработка, не дословный перевод.
- Решение, не предписанное задачей впрямую: раздел «Контекст» в
  `implementer.md` (с {МЕСТО_В_ПРОЕКТЕ}, {ИНТЕРФЕЙСЫ},
  {ГЛОБАЛЬНЫЕ_ОГРАНИЧЕНИЯ}) — задача перечисляет эти три подстановки как
  часть тела шаблона, но не называет для них отдельного заголовка среди
  шести обязательных разделов. Я вынес их в собственный раздел «Контекст»
  перед «Что читать первым», по аналогии с разделом Context в оригинальном
  `implementer-prompt.md`. Это не входит в список из шести обязательных
  разделов, но и не противоречит ему — обязательные шесть разделов
  присутствуют отдельно и дословно по составу, требуемому задачей.
- В `task-reviewer.md` и `re-review.md` я добавил вводный абзац после
  заголовка (одно-два предложения, задающих рамку ревью) перед первым
  обязательным разделом — по аналогии с оригинальными промптами. Это тоже
  не входит в список обязательных разделов, но не подменяет и не дублирует
  ни один из них.
- Git-операции не выполнялись. Использовались только Read, Write, Bash
  (`mkdir`, `sed`, `grep`, `diff`, `python3` для сборки файлов из
  посимвольно извлечённых блоков — чтобы исключить ручную опечатку при
  копировании).
