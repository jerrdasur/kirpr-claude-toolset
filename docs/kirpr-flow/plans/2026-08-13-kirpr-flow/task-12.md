# Задача 12: приёмка

Шесть критериев из спеки, проверяемых целиком. Задача ничего не создаёт —
она доказывает, что созданное работает. Найденное здесь чинится здесь же.

**Файлы:**
- Изменить: любой файл набора, в котором приёмка найдёт дефект.

**Интерфейсы:**
- Потребляет: всё, что создали задачи 1-11.
- Предоставляет: ничего. Это последняя задача плана.

---

- [ ] **Шаг 1: Критерий 1 — ни одной git-команды**

```bash
grep -rnE 'git (add|commit|checkout|branch|diff|log|status|push|pull|merge|stash|rebase|worktree|rev-parse|clean|init)' skills/kirpr-flow/
```

Ожидается: совпадения только в `skills/kirpr-flow/core/rules.md`, где
перечисляются запрещённые команды. Совпадение в любом другом файле —
протечка, и она чинится здесь же.

```bash
grep -rn '\bgit\b' skills/kirpr-flow/
```

Прочитать выдачу построчно. Критерий — не список файлов, а смысл каждой
строки: совпадение обязано стоять в контексте запрета, то есть быть либо
перечнем запрещённых команд, либо объяснением, чего набор не делает, либо
причиной, по которой чего-то нельзя проверить. Совпадение в любом другом
смысле — протечка, и она чинится здесь же.

Ориентир, а не критерий: слово ожидаемо встречается в `SKILL.md`,
`core/rules.md`, `modes/finish.md`, `modes/plan.md`, `modes/brainstorm.md`,
`modes/review.md`, `modes/execute.md` и во всех шести `prompts/*.md` — в
промпты оно попадает через дословную выжимку правил. Файл вне ориентира не
делает проверку проваленной сам по себе: смотреть надо на смысл строки.

В отчёт: обе команды и их вывод целиком, плюс вердикт по каждой строке
второй выдачи.

- [ ] **Шаг 2: Критерий 3 — полнота набора**

```bash
find skills/kirpr-flow -name '*.md' | sort
```

Ожидается ровно 20 путей: `SKILL.md`, пять в `core/`, восемь в `modes/`,
шесть в `prompts/`.

Сверить со списком соответствий из спеки: у каждого из двенадцати скилов
оригинала есть файл-получатель, и этот файл существует.

```
Read docs/kirpr-flow/specs/2026-08-13-kirpr-flow-design.md
```

В отчёт: вывод `find` целиком и таблица «скил оригинала → файл → существует».

- [ ] **Шаг 3: Критерий 2 — все файлы прочитаны целиком**

Задачи 1-11 читали свои файлы по мере создания. Здесь проверяется, что ни
один файл не остался непрочитанным после последней правки: если файл правился
в задаче 12 на шаге 1, его надо прочитать целиком заново.

Прочитать целиком каждый файл, который менялся после своей задачи. Если
таких нет — записать это явно, с перечнем файлов, изменённых на шаге 1.

В отчёт: список прочитанных файлов и результат по чеклисту для каждого —
плейсхолдеры, внутренние противоречия, места с двумя прочтениями.

- [ ] **Шаг 5: Критерий 4 — сквозной прогон**

Прогон идёт во временном каталоге вне репозитория, чтобы игрушечные
артефакты не попали в `docs/kirpr-flow/`. Если у сессии есть свой каталог
для временных файлов — использовать его; иначе завести каталог вне дерева
репозитория и работать в нём. Ниже он обозначен как `$CHECK`:

```bash
mkdir -p "$CHECK" && cd "$CHECK"
```

Задача для прогона: скрипт `greet.sh`, который печатает `hello, <имя>` для
переданного аргумента и `hello, world` без аргумента.

Порядок:

1. Написать руками минимальный каталог плана по формату из
   `core/artifacts.md`: `00-overview.md` с разделом «Глобальные ограничения»
   и одна задача `task-01.md` со шагами и верификацией формата «скрипт».
2. Пройти по `modes/execute.md` дословно: подготовка, ledger, диспетч
   имплементера по `prompts/implementer.md`, приём отчёта, ревью по
   `prompts/task-reviewer.md`.
3. Пройти по `modes/finish.md` и получить сводку.

Что проверяется и записывается в отчёт по каждому пункту:

- имплементер не выполнил ни одной git-команды;
- отчёт содержит секции «Файлы» и «Верификация», и в «Верификации» есть
  команда с выводом, а не пересказ;
- ревьюер прочитал файлы целиком — это видно по его отчёту;
- `progress.md` содержит строку `Задача 1: готово (…)` в формате из
  `core/artifacts.md`;
- прервать прогон после первой задачи и перезапустить `modes/execute.md` на
  том же каталоге: режим обязан увидеть строку `готово` и не перезапускать
  задачу;
- сводка `finish` собрана из ledger и не содержит предложений про коммиты и
  слияния.

Убрать за собой:

```bash
rm -rf "$CHECK"
```
