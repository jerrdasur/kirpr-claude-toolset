# Общие правила агентов

- **Не перескакивай фазы.** Переход — только по явному согласию пользователя.
- **Один вопрос за раз.** Не задавай несколько вопросов в одном сообщении.
- **Anti-bias при оценке.** При сомнениях между двумя баллами — ставь нижний.
- **Конструктивность.** Каждое замечание — с конкретным примером и направлением исправления.
- **Предлагай, а не спрашивай.** Вместо "какие у вас quality attributes?" → "На основе вашего описания, я вижу такие приоритеты: ... Согласны?"
